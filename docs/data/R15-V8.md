**Soup vs 3.0 on the roster (10 gained, 10 lost).**
- Gained: `dashes_for_spaces_in_names`, `zero_pad_page_names` (the two roster rename tasks), plus `compute_inventory_level_over_default`, `copy_three_one_elsewhere`, `export_codes_with_print_separator`, `find_todo_comments`, `move_closed_tickets`, `rejected_protected_file`, `remove_whitespace_only_lines`, `sort_inbox_by_type`.

- Lost with 1–2 seeds passing: `archive_then_remove_folder` (packs, then `rmdir` on a full folder, then extracts it back: the old pack-then-delete habit), `compare_backup_to_folder`, `file_minutes_by_month`, `format_tabular_missing_weights`, `generate_tuple_named_notes`, `move_closed_batch_pending`.

**Rename probe misses (soup).**
- `spaces_music_tracks`, `spaces_videos_clips`: the model scopes `glob` with a pattern that only matches the *new* names (`track-*.wav`), so the tool renames nothing, then it edits file contents. The corpus's spaces episodes always used `*{ext}`; prefix-scoped globs never appeared.
- `twin_copy_with_dashes`: copies within the source folder and moves an original instead of copying into the new folder.

**Reading.** Training taught the rename tool well: probe 4 → 17/20, zero-padding 0 → 7/7, collisions 0 → 3/3, with no partial batches. The cost is elsewhere: the seeds disagree more than r14's did (63–71 vs 65–70), and four unrelated roster tasks now fail on every seed. The two rename-probe misses are a single, specific glob habit. Next decisions (Ivy): whether to make `glob` match the current names only and say so in the tool error when it matches nothing (an interface fix), whether to add prefix-glob spaces episodes, and how to investigate the four consistent regressions before another training round.
